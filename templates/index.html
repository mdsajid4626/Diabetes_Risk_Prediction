Algorithm Specifications

This system utilizes a calibrated K-Nearest Neighbors (KNN) classification algorithm trained on the standardized PIMA Indians Diabetes Database. Input parameters are normalized using StandardScaler prior to distance metric calculations to ensure uniform feature weighting.

Feature Reference Guide

  • Glucose: 2-hour post-load plasma glucose concentration from an oral glucose tolerance test (mg/dL).
  • Blood Pressure: Diastolic blood pressure (mm Hg).
  • Skin Thickness: Triceps skinfold measurement estimating subcutaneous fat distribution (mm).
  • Insulin: 2-hour serum insulin concentration (µU/mL).
  • BMI: Body Mass Index calculated as weight in kg / (height in m)².
  • Diabetes Pedigree Function: Synthesis of family genetic diabetic history based on lineage degree.
  • Age: Chronological patient age in years.
